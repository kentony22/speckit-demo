# タスク名の更新契約

`PATCH /api/tasks/{id}/name` に JSON オブジェクト `{"name":"変更後の名前"}` を送る。名前フィールドは文字列で、空白以外の文字を含む。

| 結果 | 応答 |
| --- | --- |
| 成功 | `200` と既存のタスク応答 |
| 名前が未入力、空白のみ、文字列以外 | `400 TASK_NAME_REQUIRED` |
| タスクが見つからない | `404 TASK_NOT_FOUND` |
| 保存に失敗 | `503 TASK_STORAGE_UNAVAILABLE` |

名前だけを更新する。既存の登録、取得、完了操作の契約は維持する。
