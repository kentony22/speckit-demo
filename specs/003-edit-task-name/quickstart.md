# ローカル確認

1. [README](../../README.md) に従い、Cosmos DB エミュレーターとフロント・バックエンドを起動する。検証専用の `TODO_OWNER_ID` を指定する。
2. タスクを2件登録し、1件を完了にする。完了済みタスクをクリックして詳細パネルを開き、タスク名テキストボックスを書き換えて Enter（またはフォーカス外れ）で保存する。名前だけが変わり、2件のままで、再読み込み後も新しい名前と完了が確認できる（AC-001、AC-002）。
3. 詳細パネルのタスク名テキストボックスで別の名前を入力し、Escape キーでキャンセルする。保存済みの名前へ戻る（AC-003）。
4. 空欄、半角空白だけ、全角空白だけを別々に Enter（またはフォーカス外れ）で確定しようとする。入力エラーが表示され、保存済みの名前が保持される（AC-004）。
5. 名前の更新リクエストを検証用ブラウザーで一度だけ 503 にし、有効な名前を保存する。失敗の表示、保存済みの名前、同じ入力での再試行を確認する（AC-005）。
6. README のトラストストアを指定してバックエンドで `./mvnw -B -ntp verify` を実行し、フロントエンドで `npm ci`、`npm run build` を実行する。
