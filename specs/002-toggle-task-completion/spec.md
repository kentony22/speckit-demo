# Feature Specification: タスクの完了と未完了への切り替え

**Feature Branch**: `main`（仕様作成時）

**Created**: 2026-11-21

**Status**: Draft

**Input**: 個人ユーザーが登録済みタスクを一覧で完了にし、必要に応じて未完了に戻せるようにする。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一覧からタスクの完了状態を切り替える (Priority: P1)

個人ユーザーとして、やり終えたタスクに完了の印を付けたい。再び対応が必要になったときは未完了に戻し、次にページを開いたときも残っている作業が分かるようにしたい。

**Why this priority**: 一覧で完了状態を確認できれば、何を終えて何が残っているかを把握できる。

**Independent Test**: 機能追加前に登録した1件と新しく登録した1件がある状態から、既存タスクを完了にして再読み込みし、未完了に戻して再度再読み込みする。各操作後に、対象タスクともう一方のタスクの表示を確認する。

**Acceptance Scenarios**:

1. **AC-001** — **前提** 一覧に未完了のタスクが複数ある。**操作** そのうち1件を完了にする。**期待結果** 対象のタスクは同じ一覧に残り、完了済みと分かる。ほかのタスクの状態は変わらない。
2. **AC-002** — **前提** 完了済みのタスクが一覧にある。**操作** そのタスクを未完了に戻す。**期待結果** 同じタスクが未完了として表示される。
3. **AC-003** — **前提** 状態の変更が成功した。**操作** ページを再読み込みする。**期待結果** 完了にした場合は完了済み、未完了に戻した場合は未完了として表示される。
4. **AC-004** — **前提** 機能追加前に登録され、完了状態を持たないタスクがある。**操作** 一覧を開き、そのタスクを完了にする。**期待結果** 既存のタスク名のまま未完了として表示され、完了の操作後は完了済みと分かる。
5. **AC-005** — **前提** タスクの一覧を開いている。**操作** 新しいタスクを1件登録する。**期待結果** 同じ一覧に未完了のタスクが1件追加される。
6. **AC-006** — **前提** 状態の変更を保存できない。**操作** 一覧でタスクの状態を切り替える。**期待結果** 変更できなかったことが分かり、変更前の状態で引き続き操作できる。

### Edge Cases

- 完了状態を持たない既存のタスクは、未完了として操作できる（AC-004）。
- 変更を保存できなかったときは、変更前の表示に戻り、操作をやり直せる（AC-006）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** — 一覧の各タスクで完了と未完了を切り替えられる。操作の対象は選んだ1件とする（AC-001、AC-002）。
- **FR-002** — 完了済みのタスクを同じ一覧に残し、状態を示す文言や記号で未完了のタスクと区別できるようにする（AC-001、AC-002）。
- **FR-003** — 成功した変更を対象タスクに保存し、再読み込み後は最後に保存した状態を表示する（AC-003）。
- **FR-004** — 完了状態を持たない既存タスクを未完了として扱い、タスク名を保ったまま完了にできるようにする。新しく登録したタスクの初期状態も未完了とする（AC-004、AC-005）。
- **FR-005** — 状態を保存できない場合は、変更前の状態を表示し、操作が失敗したことを伝えて再試行できるようにする（AC-006）。

### Key Entities

- **タスク** — 個人ユーザーが登録した用事。タスク名と、未完了または完了の状態を持つ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001** — 2件の未完了タスクのうち1件を一覧から1回の操作で完了にできる。完了1件と未完了1件を同じ一覧で見分けられ、一覧の件数は2件のままとなる。
- **SC-002** — 同じタスクを完了にして1回再読み込みし、次に未完了へ戻して1回再読み込みする。各回で、直前に変更した状態が表示される。
- **SC-003** — 機能追加前に登録したタスク1件と新規タスク1件を未完了として確認できる。既存タスクを完了にすると、そのタスク名と完了状態を同じ一覧で確認できる。

## Assumptions

- [001-add-list-tasks の仕様](../001-add-list-tasks/spec.md) にある、個人ユーザー1人のタスク登録・一覧を前提とする。
- 状態の切り替えは現在の一覧内で行い、表示順は登録時と同じルールに従う。
- 今回の対象は完了状態の表示と切り替え。タスク名の編集、削除、重要の指定、カスタムリスト、検索、状態による絞り込みは範囲外とする。
