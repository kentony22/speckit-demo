# Feature Specification: タスクの削除

**Feature Branch**: `feature/007-delete-task`

**Created**: 2026-11-21

**Status**: Draft

**Input**: User description: "削除機能を追加して。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - タスクの削除 (Priority: P1)

個人ユーザーとして、不要になったタスクや誤って登録したタスクを一覧から削除し、残りのタスクだけをすっきり管理したい。

**Why this priority**: 不要なタスクを取り除けないと一覧が増え続け、重要なタスクや残っている用事を見つけにくくなるため。

**Independent Test**: 登録済みのタスク2件から1件を削除し、削除後の表示・再読み込み後の非表示・キャンセル時の維持・失敗時の再試行を単独で確認できる。

**Acceptance Scenarios**:

1. **AC-001** — **前提** 登録済みのタスクが2件ある。 **操作** 1件を選び、削除操作から削除を確定する。 **期待結果** 選んだ1件だけが一覧から消え、もう1件のタスクとその状態（名前・完了・重要・所属リスト）は維持される。
2. **AC-002** — **前提** タスク1件の削除が確定された。 **操作** ページを再読み込みする。 **期待結果** 削除したタスクは再表示されず、残りのタスクだけが表示される。
3. **AC-003** — **前提** 削除の確認状態になっている。 **操作** 削除をキャンセルする。 **期待結果** 確認表示が閉じ、対象タスクは削除されず一覧に残る。
4. **AC-004** — **前提** 「重要」ビュー、カスタムリスト、または検索結果の一覧を表示している。 **操作** 表示中のタスク1件を削除確定する。 **期待結果** 現在のビューや検索条件を維持したまま対象タスクだけが消え、表示件数が0件になった場合はその画面の空状態メッセージが表示される。
5. **AC-005** — **前提** 削除を保存できない状態である。 **操作** タスクの削除を確定する。 **期待結果** 削除失敗が表示され、対象タスクは一覧に残ったまま再試行できる。

### Edge Cases

- 完了済みタスク、重要タスク、カスタムリストに所属するタスク、および旧形式で登録されたタスクのいずれも削除できる。
- 確認中にキャンセルした場合は削除を実行しない（AC-003）。
- 削除に失敗した場合でもタスクは一覧に残り、再試行で削除できる（AC-005）。
- 存在しないタスクやタスク以外のデータ（カスタムリスト等）を誤って削除対象にしても、既存のタスクやカスタムリストは影響を受けない。
- 削除操作の連打や二重送信が発生しても、意図しない別タスクの削除は起きない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** — 一覧上の各タスクに対して削除操作を提供し、確認後に選択した1件だけを削除して他のタスクとカスタムリストを維持する（AC-001）。
- **FR-002** — 削除を永続化し、ページを再読み込みしても削除済みタスクを再表示しない（AC-002）。
- **FR-003** — 削除を確定する前に確認ステップを設け、キャンセルした場合は削除を行わず一覧に戻る（AC-003）。
- **FR-004** — 「すべてのタスク」「重要」「カスタムリスト」「検索結果」のいずれの画面からでも削除でき、削除後は現在の画面や検索条件を維持したまま表示を更新する（AC-004）。
- **FR-005** — 削除を完了できない場合は失敗メッセージを表示し、対象タスクを一覧に残したまま再試行できるようにする（AC-005）。

### Key Entities *(include if feature involves data)*

- **タスク** — 登録済みの用事。削除操作により1件単位で取り除かれる。
- **カスタムリスト** — タスクを分類する一覧。所属していたタスクを削除してもカスタムリスト自体は保持される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001** — 2件のタスクから選んだ1件を2操作以内（削除開始と確定）で削除でき、1回の再読み込み後も削除済みタスクが再表示されず残り1件が保持される。
- **SC-002** — 確認画面からのキャンセル操作1回で、対象タスクが一覧と再読み込み後の両方で100%保持される。
- **SC-003** — 「重要」ビュー・カスタムリスト・検索結果の各画面からタスクを削除しても、画面遷移せず元のビューまたは検索状態を維持したまま結果が即時反映される。

## Assumptions

- [001-add-list-tasks](../001-add-list-tasks/spec.md)〜[006-search-task-names](../006-search-task-names/spec.md) の登録・一覧・完了・名前編集・重要マーク・カスタムリスト・検索を前提とする。
- 今回はタスク1件の完全削除を対象とする。ゴミ箱・削除の取り消し（Undo）・複数選択による一括削除・カスタムリスト自体の削除は別機能とする。
- 誤削除を防ぐため、削除確定前に1段階の確認ステップ（確定／キャンセル）を設ける。
