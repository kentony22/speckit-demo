# データモデル

## Task

- `Task.id` は削除対象を特定する一意な識別子。サーバー側の所有者パーティション（`ownerId`）内のタスク文書を対象とし、カスタムリスト識別子（`list-` プレフィックス）は削除対象外とする。
- `Task` の削除は対象1件の文書のみを物理削除する。同じパーティション内の他タスクおよび `TaskList` 文書には影響しない。
- 画面上の削除操作状態は行単位で管理する（`idle` → `confirming` → `deleting`）。
  - `confirming` からキャンセルした場合は `idle` に戻り、削除要求は送信しない。
  - `deleting` が成功した場合は全タスク状態から対象 `Task.id` を除外する。
  - `deleting` が失敗した場合は `confirming` 状態のままエラー表示を維持し、同じ行から再試行またはキャンセルできる。
