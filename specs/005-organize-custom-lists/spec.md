# Feature Specification: カスタムリスト

**Feature Branch**: `main`（仕様作成時）

**Created**: 2026-11-21

**Status**: Draft

**Input**: リストを作り、登録済みタスクを用途ごとに振り分けられるようにする。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - カスタムリスト (Priority: P1)

個人ユーザーとして、買い物や仕事など、用途別の一覧でタスクを確認したい。

**Why this priority**: 用途を選ぶだけで、関連するタスクに絞って確認できる。

**Independent Test**: リスト2件を作り、既存タスクを片方に割り当てる。もう一方へ移動して再読み込みし、割り当てを解除して「すべてのタスク」を確認する。

**Acceptance Scenarios**:

1. **AC-001** — **前提** カスタムリストを作成できる画面を開いている。 **操作** 有効な名前でリストを作り、選択する。 **期待結果** 作ったリストが画面左側に表示され、選ぶとそのリストが開く。空のリストではタスクが未登録であると分かる。
2. **AC-002** — **前提** 「すべてのタスク」にタスク2件と、空のリスト2件がある。 **操作** タスク1件を最初のリストに割り当て、リストを切り替える。 **期待結果** 最初のリストに選んだ1件だけが表示され、別のリストは空のままとなる。「すべてのタスク」には2件が残る。
3. **AC-003** — **前提** タスクが一方のリストに割り当てられている。 **操作** もう一方へ移動し、移動先、移動元、「すべてのタスク」を確認してから再読み込みする。 **期待結果** 移動先に表示され、移動元から消える。「すべてのタスク」では同じタスクが1件だけ表示される。再読み込み後も両方のリストを選べ、所属先・名前・完了状態が保たれる。
4. **AC-004** — **前提** タスクがリストに割り当てられている。 **操作** 割り当てを解除する。 **期待結果** そのリストからタスクが外れ、「すべてのタスク」で同じタスクを確認できる。
5. **AC-005** — **前提** リストを作成しようとしている。 **操作** 空欄または空白だけの名前で作成を試みる。 **期待結果** 入力エラーが表示され、リストの件数は変わらない。
6. **AC-006** — **前提** リストの作成または割り当ての変更を保存できない。 **操作** 作成または変更を試みる。 **期待結果** 失敗が表示され、最後の保存状態から再試行できる。

### Edge Cases

- 空のリストには未登録であることを示す（AC-001）。
- リストに属さないタスクは「すべてのタスク」で確認できる（AC-004）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** — 空白以外を含む名前でカスタムリストを作成できる。作成したリストを画面左側に表示し、選ぶと開く。空欄・空白だけの場合は入力エラーを表示し、作成を行わない（AC-001、AC-005）。
- **FR-002** — 選択したリストに割り当てられたタスクだけを表示する。0件のときは未登録と分かる表示にする（AC-001、AC-002）。
- **FR-003** — 各タスクを最大1件のカスタムリストに割り当てられる。移動と解除ができ、「すべてのタスク」には各タスクが1件ずつ残る（AC-002〜AC-004）。
- **FR-004** — 作成済みリストと割り当てを再読み込み後も使えるようにする。保存失敗時は失敗を表示して再試行できるようにする（AC-003、AC-006）。

### Key Entities

- **カスタムリスト** — 利用者が名前を付けて作る、0件以上のタスクのまとまり。
- **タスク** — 「すべてのタスク」に表示され、任意で1件のカスタムリストに割り当てられる。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001** — タスク2件とリスト2件で、1件を割り当てると各リストで割り当て件数と表示件数が一致し、「すべてのタスク」では2件を確認できる。
- **SC-002** — 移動後に1回再読み込みすると、両方のリストを選べて対象タスクは移動先で確認できる。解除後も「すべてのタスク」に残る。

## Assumptions

- [001-add-list-tasks](../001-add-list-tasks/spec.md) の一覧を「すべてのタスク」として使う。既存タスクと、従来の入力欄から登録したタスクは未割り当てから始まる。
- 初回は作成・閲覧・割り当てを対象とする。リスト名の変更、削除、複数所属、共有は別機能とする。
