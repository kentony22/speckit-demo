# Quickstart — カスタムリスト

リポジトリの [README](../../README.md) に沿って、Cosmos DB エミュレーター、バックエンドとフロントエンドを起動する。検証ごとに固有の `TODO_OWNER_ID` を指定する。別 worktree と同時に試す場合はフロントエンドをビルドし、`backend` で `./mvnw -Pbundled-web package` を実行して、固有のポートでアプリを起動する。

1. 「リスト名」に「買い物」と「仕事」を入力してそれぞれ作成し、左側から選ぶ。どちらにも空の表示が出ることを確認する。
2. 「すべてのタスク」でタスクを2件作る。片方を選び「所属先」で「買い物」に移し、リストごとの件数と全件2件を確認する。
3. 対象タスクを完了にしてから「仕事」に移す。移動元が空、移動先が1件、全件一覧で対象が1件と確認する。再読み込みし、リスト、所属先、名前、完了状態を確認する。
4. 所属先を「リストなし」に戻す。「仕事」から消え、全件一覧に残ることを確認する。
5. 空欄または半角・全角空白だけでリストを作成し、入力エラーと件数の維持を確認する。
6. ブラウザーのリクエストモックで作成と移動の各応答を一度だけ 503 にし、エラー表示と最後の保存状態を確認する。次の操作で成功することを確認する。

`frontend` の `npm run build` と、エミュレーターへ接続できる状態で `backend` の `./mvnw verify` を実行する。結合テストで [HTTP 契約](contracts/task-lists.md) と [保存モデル](data-model.md) を検証する。
