# Data Model: タスク名の検索

| 項目 | 内容 |
| --- | --- |
| タスク | 既存の `Task`。照合に使うのは `name`。表示には元のタスクを使う |
| 全タスク | 既存の全件一覧を表示順のまま保持する |
| 通常ビューのタスク | ナビゲーションが選択したビューの表示順と絞り込みを反映した一覧。基準ブランチでは全タスク |
| 検索語 | 入力欄の値。検索時に前後の空白を除き、小文字化する |
| 表示一覧 | 有効な検索語があれば全タスクから名前が一致するものを抽出する。空欄・空白のみで通常ビューのタスクを表示する |

入力操作でタスクの内容、順序、ビューの選択は変化しない。検索中の一致が0件の場合も、読み込み完了後にだけ空結果を表示する。
