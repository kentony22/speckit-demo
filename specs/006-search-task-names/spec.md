# Feature Specification: タスク名の検索

**Feature Branch**: `main`（仕様作成時）

**Created**: 2026-11-21

**Status**: Draft

**Input**: 所属リストをまたいで、登録済みのタスクを名前で検索できるようにする。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - タスク名の検索 (Priority: P1)

個人ユーザーとして、名前の一部しか覚えていなくても目的のタスクを見つけたい。

**Why this priority**: 全件を順に読み直す手間を減らせる。

**Independent Test**: 別々のリストにある一致タスク2件と一致しない1件で検索する。該当なしも確認し、検索欄を空にして開始前のリストに戻る。

**Acceptance Scenarios**:

1. **AC-001** — **前提** 別々のリストに「Azureに配備する」と「Azureの手順を確認する」があり、ほかに名前に「Azure」を含まないタスクがある。 **操作** いずれかのリストを開いた状態で「Azure」と入力する。 **期待結果** 所属リストをまたいで、名前に一致する2件だけが「すべてのタスク」を基準にした相対順で表示される。
2. **AC-002** — **前提** 「Azure の準備」というタスクがある。 **操作** 前後に空白を含む「 azure 」で検索する。 **期待結果** 英字の大文字・小文字と検索語の前後の空白にかかわらず一致する。
3. **AC-003** — **前提** 登録済みのタスクがある。 **操作** 一致する名前がない語で検索する。 **期待結果** 「一致するタスクがありません」と表示される。
4. **AC-004** — **前提** カスタムリストまたは「重要」ビューから検索を開始し、結果を表示している。 **操作** 検索語を消すか、空白だけにする。 **期待結果** 検索前に開いていたビューまたはリストに戻り、その一覧が表示される。

### Edge Cases

- 空欄・空白だけの入力では検索前のビューまたはリストに戻る（AC-004）。
- 検索の該当なしと、全件一覧でのタスク未登録は区別して表示する（AC-003）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** — 検索語を名前に含むタスクを所属リストや完了状態にかかわらず抽出し、「すべてのタスク」を基準にした相対順で表示する（AC-001）。
- **FR-002** — 検索語の前後の空白を無視し、英字の大文字と小文字を区別しない（AC-002）。
- **FR-003** — 一致するタスクが0件の場合は「一致するタスクがありません」と表示する（AC-003）。
- **FR-004** — 検索欄を空欄・空白のみにすると、検索前のビューまたはリストを表示する。検索や解除で登録済みのタスクの内容は変わらない（AC-004）。

### Key Entities

- **タスク** — 登録済みの用事。検索対象の項目はタスク名。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001** — 3件中2件の名前に共通する語で1回検索すると、所属リストをまたいでその2件だけを確認できる。
- **SC-002** — 一致しない語で1回検索すると該当なしが表示され、語を消すと開始前のビューまたはリストに戻る。「重要」ビューとカスタムリストの両方で確認する。

## Assumptions

- [001-add-list-tasks](../001-add-list-tasks/spec.md) の全件一覧と [002-toggle-task-completion](../002-toggle-task-completion/spec.md) の完了状態を前提とする。[重要ビュー](../004-mark-task-important/spec.md) や [カスタムリスト](../005-organize-custom-lists/spec.md) から始めても、検索対象は登録済みの全タスクとする。
- 初回は名前の部分一致を対象とする。検索履歴、あいまい検索、リスト名などの検索は別機能とする。
