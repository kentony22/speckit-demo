# Quickstart: 重要指定の検証

[README](../../README.md) のローカル起動手順で、Cosmos DB エミュレーター、JDK 25、Node.js を用意する。試験用の `TODO_OWNER_ID` を指定する。 `backend` で `./mvnw verify`、`frontend` で `npm ci` と `npm run build` を実行する。

| 受け入れ条件 | 操作と期待結果 |
| --- | --- |
| AC-001 | 2件登録し片方を完了にする。そのタスクに重要マークを付ける。元の一覧の順序と完了状態が保たれ、「重要」にはその1件が表示される。 |
| AC-002 | 「重要」でマークを外す。そのビューは0件になり、元の一覧では2件のままで完了状態も保たれる。 |
| AC-003 | 付与・解除のたびに再読み込みする。元の一覧と「重要」で保存した状態が確認できる。 |
| AC-004 | 重要項目を持たない旧形式タスクを用意する。未指定で表示され、マークを付けられる。既存テストの専用パーティションの文書でも確認できる。 |
| AC-005 | 更新 API が失敗するようにしてマークを操作する。最後に保存した状態とエラーが表示され、API を復旧すると同じボタンで保存できる。 |

[エンドポイントと応答](contracts/importance.md) と [旧文書の扱い](data-model.md) は設計資料を参照する。
