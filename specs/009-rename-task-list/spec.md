# Feature Specification: カスタムリスト名の編集

**Feature Branch**: `feature/009-rename-task-list`

**Created**: 2026-11-22

**Status**: Draft

**Input**: User description: "リスト名を編集できる機能を追加する。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - カスタムリスト名の編集 (Priority: P1)

個人ユーザーとして、作成済みカスタムリストの用途や分類名の変更に合わせて、リスト名を作り直すことなく修正したい。

**Why this priority**: リストを作り直してタスクを移し替える手間を省き、サイドバーと所属表示を常に分かりやすい名前に保てるため。

**Independent Test**: カスタムリスト2件（うち1件はグループ所属かつタスク所属あり）を用意し、1件のリスト名変更・再読み込み・キャンセル・空白エラー・保存失敗からの再試行を単独で確認できる。

**Acceptance Scenarios**:

1. **AC-001** — **前提** カスタムリストが2件あり、1件にはタスクとリストグループが割り当てられている。 **操作** そのカスタムリストの名前を空白以外を含む新しい名前へ変更して保存する。 **期待結果** 選んだ1件だけの名前が画面左側ナビゲーション・選択中リストの見出し・各タスクの所属リスト表示（一覧サブテキスト・詳細パネル）に反映され、もう1件のリスト、グループ所属、および所属タスクはすべて維持される。
2. **AC-002** — **前提** カスタムリスト名の変更が保存された。 **操作** ページを再読み込みする。 **期待結果** 変更後のリスト名が表示され、グループ所属とリスト内のタスクが維持される。
3. **AC-003** — **前提** カスタムリスト名を編集中である。 **操作** 名前を変更してキャンセルする。 **期待結果** 編集が閉じ、元の名前のまま維持される。
4. **AC-004** — **前提** カスタムリスト名を編集中である。 **操作** 名前を空欄、半角空白だけ、全角空白だけのいずれかにして保存を試みる。 **期待結果** 入力エラーが表示され、保存は行われず元の名前が維持される。
5. **AC-005** — **前提** リスト名を保存できない状態である。 **操作** 有効な名前で保存を試みる。 **期待結果** 失敗メッセージが表示され、保存済みのリスト名と再試行に使う入力内容が保たれる。

### Edge Cases

- 空欄、半角空白だけ、全角空白だけは保存不可とする（AC-004）。
- 保存に失敗しても編集中の入力と保存済みの名前を維持する（AC-005）。
- グループに所属しているカスタムリスト・未分類のカスタムリストのいずれでも名前を変更でき、変更後もグループ所属とタスク所属は変化しない。
- 存在しないカスタムリスト、別所有者のカスタムリスト、またはタスクやリストグループに対する名前変更要求は拒否され、既存データは変化しない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** — 作成済みカスタムリストの名前を空白以外を含む新しい名前に変更でき、画面左側ナビゲーション・リスト見出し・タスクの所属リスト表示へ即時反映し、他リスト・グループ所属・所属タスクを維持する（AC-001）。
- **FR-002** — 変更したカスタムリスト名を永続化し、ページを再読み込みしても変更後の名前を表示する（AC-002）。
- **FR-003** — 編集をキャンセルすると保存を行わず、元の名前のまま表示に戻る（AC-003）。
- **FR-004** — 空欄・空白だけの入力では保存を行わず、入力エラーを表示する（AC-004）。
- **FR-005** — 保存できない場合は失敗メッセージを表示し、保存済みの名前と編集中の入力を維持したまま再試行できるようにする（AC-005）。

### Key Entities *(include if feature involves data)*

- **カスタムリスト** — 名前を持つタスクの分類一覧。編集対象はリスト名であり、識別子・グループ所属・所属タスクは維持される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001** — 2件のカスタムリストから選んだ1件だけを1回の保存で変更でき、1回の再読み込み後も変更後の名前・グループ所属・所属タスクが100%保持される。
- **SC-002** — キャンセル1回と、空欄・半角空白・全角空白での3回の保存試行のそれぞれで、保存済みのリスト名が100%維持される。

## Assumptions

- [005-organize-custom-lists](../005-organize-custom-lists/spec.md) のカスタムリストおよび [008-list-groups](../008-list-groups/spec.md) のリストグループを前提とする。
- 今回はカスタムリスト名の変更を対象とする。カスタムリスト自体の削除や並び替えは別機能とする。
- 「すべてのタスク」「重要」などの組み込みビューの名前は変更対象外とする。
